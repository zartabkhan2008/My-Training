JavaScript Variables

Definition

In JavaScript, a variable is a container used to store data values. You can create variables using let, const, or var.

1. let (Changeable value)

``` let age = 25; age = 26; console.log(age); // 26
```

2. const (Fixed value)

``` const pi = 3.14159; // pi = 3.14; ❌ Error console.log(pi);
```

3. var (Old method)

``` var name = "John"; name = "Mike"; console.log(name); // Mike
```

Variable Naming Rules

✅ Valid:

``` let userName; let _count; let $price; let age1; ```

❌ Invalid:

``` let 1age; let user-name; let let;
```

Data Types

``` let name = "Alice"; // String let age = 30; // Number let isStudent = true; // Boolean let city = null; // Null let score; // Undefined
```

Example

``` let firstName = "John"; let lastName = "Doe"; let age = 25; console.log(firstName + " " + lastName); console.log("Age:", age); ```

Output:

``` John Doe Age: 25
```

Best Practice

Use const by default, and use let only when the value needs to change. Avoid var in modern JavaScript.
