JavaScript Data Types

Understanding Primitive and Non-Primitive Data Types

1. String

Represents text enclosed in quotes.

let name = "Zartab";
console.log(typeof name); // string

2. Number

Represents numeric values (integer or floating-point).

let age = 25;
let price = 99.99;
console.log(typeof age); // number

3. Boolean

Represents logical values: true or false.

let isStudent = true;
console.log(typeof isStudent); // boolean

4. Undefined

A variable declared but not assigned has the value undefined.

let x;
console.log(typeof x); // undefined

5. Null

Represents an intentional "empty" value.

let data = null;
console.log(typeof data); // object (special case)

6. Symbol

Represents unique identifiers.

let sym = Symbol("id");
console.log(typeof sym); // symbol
