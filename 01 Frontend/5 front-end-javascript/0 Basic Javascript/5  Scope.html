JavaScript Scope

Understand different types of scope with examples

Global Scope

Definition: Variables declared outside any function or block are in the global scope and accessible everywhere.

// Example
var globalVar = "I am global";

function showGlobal() {
  console.log(globalVar); // Accessible here
}

showGlobal();
console.log(globalVar); // Accessible here too

Explanation: Global variables can be accessed from any part of the program. Overusing them can cause conflicts.

Local Scope

Definition: Variables declared inside a function are local to that function and cannot be accessed outside.

// Example
function localExample() {
  let localVar = "I am local";
  console.log(localVar); // Accessible here
}

localExample();
// console.log(localVar); ❌ Error: not defined

Explanation: Local variables exist only within the function where they are declared.

Block Scope

Definition: Variables declared with let or const inside a block ({ }) are only accessible within that block.

// Example
{
  let blockVar = "Inside block";
  console.log(blockVar); // Accessible here
}
// console.log(blockVar); ❌ Error: not defined

Explanation: Block scope helps prevent variables from leaking outside of loops, conditionals, or other blocks.

Lexical Scope

Definition: Inner functions can access variables from their outer functions due to lexical scoping.

// Example
function outer() {
  let outerVar = "Outer variable";
  
  function inner() {
    console.log(outerVar); // Accessible due to lexical scope
  }
  
  inner();
}

outer();

Explanation: Lexical scope means functions remember the scope in which they were created, allowing inner functions to access outer variables.
