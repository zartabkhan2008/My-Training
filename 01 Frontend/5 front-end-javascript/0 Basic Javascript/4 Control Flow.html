JavaScript Control Flow

Understand conditional statements and loops with examples

if Statement

Definition: Executes a block of code if a specified condition is true.

// Example
let age = 18;
if (age >= 18) {
  console.log("You are an adult");
}

Explanation: The if statement checks a condition. If true, the code inside runs.

else Statement

Definition: Executes a block of code if the if condition is false.

// Example
let age = 16;
if (age >= 18) {
  console.log("You are an adult");
} else {
  console.log("You are a minor");
}

Explanation: The else block provides an alternative path when the condition fails.

else if Statement

Definition: Allows multiple conditions to be checked sequentially.

// Example
let score = 75;
if (score >= 90) {
  console.log("Grade A");
} else if (score >= 75) {
  console.log("Grade B");
} else {
  console.log("Grade C");
}

Explanation: else if lets you test multiple conditions in order.

switch Statement

Definition: Executes one block of code based on matching a value.

// Example
let day = "Monday";
switch(day) {
  case "Monday":
    console.log("Start of the week");
    break;
  case "Friday":
    console.log("Weekend is near");
    break;
  default:
    console.log("Midweek day");
}

Explanation: switch is useful when checking one variable against many possible values.

for Loop

Definition: Repeats a block of code a specific number of times.

// Example
for (let i = 1; i <= 5; i++) {
  console.log("Iteration " + i);
}

Explanation: The for loop is commonly used when the number of iterations is known.

while Loop

Definition: Repeats a block of code while a condition is true.

// Example
let count = 1;
while (count <= 3) {
  console.log("Count is " + count);
  count++;
}

Explanation: The while loop runs until the condition becomes false.

do-while Loop

Definition: Executes a block of code once, then repeats while the condition is true.

// Example
let num = 1;
do {
  console.log("Number is " + num);
  num++;
} while (num <= 3);

Explanation: The do-while loop guarantees the code runs at least once, even if the condition is false initially.
