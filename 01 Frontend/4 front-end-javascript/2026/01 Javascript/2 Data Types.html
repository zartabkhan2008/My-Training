JavaScript Data Types

Primitive vs Non-Primitive with examples

Primitive Data Types

These are the most basic data types in JavaScript. They are immutable and stored by value.

String

Definition: Represents text enclosed in quotes.

let greeting = "Hello World";
console.log(greeting); // Hello World

Explanation: Strings are used to store and manipulate text.

Number

Definition: Represents numeric values (integers, floats).

let age = 25;
let price = 99.99;
console.log(age + price); // 124.99

Explanation: JavaScript uses one Number type for all numeric values.

Boolean

Definition: Represents logical values: true or false.

let isActive = true;
let isLoggedIn = false;
console.log(isActive && isLoggedIn); // false

Explanation: Booleans are used in conditions and logical operations.

Null

Definition: Represents intentional absence of value.

let data = null;
console.log(data); // null

Explanation: Explicitly assigned to indicate "no value".

Undefined

Definition: A variable declared but not assigned a value.

let result;
console.log(result); // undefined

Explanation: Means the variable exists but has no value yet.

Non-Primitive Data Types

These are complex data types. They are mutable and stored by reference.

Object

Definition: A collection of key-value pairs.

let person = {
  name: "Alice",
  age: 30,
  isStudent: false
};
console.log(person.name); // Alice

Explanation: Objects store structured data. Properties can be accessed via dot or bracket notation.

Array

Definition: An ordered list of values, indexed starting at 0.

let colors = ["red", "green", "blue"];
console.log(colors[1]); // green

Explanation: Arrays hold multiple values and provide useful methods like push(), map(), etc.
