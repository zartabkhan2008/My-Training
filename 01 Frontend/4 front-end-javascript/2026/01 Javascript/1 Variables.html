JavaScript Variables: var, let, const

Understand the differences with examples

var

Definition: Declares a variable globally or function-scoped. Can be re-declared and updated.

// Example with var
var name = "Alice";
console.log(name); // Alice

var name = "Bob"; // re-declared
console.log(name); // Bob

Explanation: Variables declared with var are hoisted to the top of their scope. They can be re-declared, which may cause bugs in larger programs.

let

Definition: Declares a block-scoped variable. Can be updated but not re-declared in the same scope.

// Example with let
let age = 25;
console.log(age); // 25

age = 30; // updated
console.log(age); // 30

// let age = 40; ❌ Error: cannot re-declare in same scope

Explanation: let is safer than var because it respects block scope and prevents accidental re-declarations.

const

Definition: Declares a block-scoped constant. Must be initialized and cannot be reassigned.

// Example with const
const PI = 3.14159;
console.log(PI); // 3.14159

// PI = 3.14; ❌ Error: cannot reassign

// Objects with const
const person = { name: "Alice" };
person.name = "Bob"; // allowed (object properties can change)
console.log(person.name); // Bob

Explanation: const ensures the variable identifier cannot be reassigned. However, objects and arrays declared with const can still have their contents modified.
