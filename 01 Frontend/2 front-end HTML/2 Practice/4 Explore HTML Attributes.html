Global Attributes (usable on most HTML elements)

  • id: Unique identifier for an element
  • class: Assigns one or more class names
  • : inline css styling
  • title: Tooltip text on hover
  • accesskey: Keyboard shortcut

Media Attributes

  • src: Source URL for images, videos, scripts
  • alt: Alternative text for images
  • width / height: Dimensions
  • controls: Adds playback controls to media
  • loop: Repeats media playback

Link & Navigation Attributes

  • href: Destination URL for links
  • target: Specifies where to open the link
  • rel: Relationship between linked documents
  • download: Prompts file download

Form Attributes

  • action: URL to send form data
  • method: HTTP method (GET or POST)
  • name: Name of the form or input
  • value: Default value
  • placeholder: Hint text

Script & Meta Attributes

  • async / defer: Script loading behavior
  • charset: Character encoding
  • content: Metadata value
  • http-equiv: HTTP header equivalent
