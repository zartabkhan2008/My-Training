🔑 What is a Function?

https://www.youtube.com/watch?v=SHINoHxvTso

Functions in JavaScript are reusable blocks of code designed to perform specific tasks. They allow you to organize, reuse, and modularize code. It can take inputs, perform actions, and return outputs.

Learn Function

JavaScript Functions Made Easy

Example:


function sayHello() {
  console.log("Hello, Students!");
}

sayHello(); // Output: Hello, Students!

Here, sayHello is the recipe name. When we call it, it prints "Hello, Students!".

📦 Parameters and Arguments


function greet(name) {
  console.log("Hello " + name);
}

greet("Ali");   // Hello Ali
greet("Sara");  // Hello Sara

🛠 Types of Functions

  • Named Function: Has a name. Example: function greet() {}
  • Anonymous Function: No name, stored in a variable. Example: const greet = function() {}
  • Arrow Function: Short way to write. Example: const add = (a, b) => a + b;
  • IIFE: Runs immediately. Example: (function(){ console.log("Hi!"); })();

🎯 Why Use Functions?

Functions make life easier because:

  • ✅ You don’t repeat code.
  • ✅ You can organize your program.
  • ✅ You can give different inputs and get different outputs.
  • ✅ Easier to fix mistakes.

🚀 Beginner Tips

👉 Always give clear names like calculateMarks instead of func1.

👉 Use default values if no input is given:


function greet(name = "Guest") {
  console.log("Hello " + name);
}
greet(); // Hello Guest

👉 Start with small functions that do one simple job.
