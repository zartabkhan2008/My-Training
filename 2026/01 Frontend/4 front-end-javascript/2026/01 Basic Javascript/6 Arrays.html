JavaScript Arrays

A beginner-friendly guide with examples

What is an Array?

Definition: An array is a special variable that can hold multiple values at once. Think of it like a list.

// Example
let fruits = ["Apple", "Banana", "Mango"];
console.log(fruits); // ["Apple", "Banana", "Mango"]

Explanation: Instead of creating separate variables for each fruit, we store them together in one array.

Accessing Elements

Definition: Each item in an array has a position called an index, starting at 0.

// Example
let colors = ["Red", "Green", "Blue"];
console.log(colors[0]); // Red
console.log(colors[1]); // Green

Explanation: Use square brackets [] with the index number to get a value.

Adding Elements

Definition: You can add new items to an array using push().

// Example
let animals = ["Dog", "Cat"];
animals.push("Elephant");
console.log(animals); // ["Dog", "Cat", "Elephant"]

Explanation: push() adds an item to the end of the array.

Removing Elements

Definition: You can remove the last item using pop().

// Example
let numbers = [1, 2, 3];
numbers.pop();
console.log(numbers); // [1, 2]

Explanation: pop() removes the last element from the array.

Looping Through Arrays

Definition: You can go through each item in an array using a loop.

// Example
let fruits = ["Apple", "Banana", "Mango"];
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
// Output:
// Apple
// Banana
// Mango

Explanation: The for loop runs through all items using the array’s length property.

Summary

  • Arrays store multiple values in one variable.
  • Index starts at 0 (first item).
  • push() adds items, pop() removes items.
  • Use loops to go through all items.
