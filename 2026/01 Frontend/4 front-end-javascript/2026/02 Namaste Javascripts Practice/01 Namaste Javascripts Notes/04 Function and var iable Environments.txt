Variable Environment  ==>
Jahan variables aur unki values execution ke time maintain hoti hain, use Variable Environment kehte hain
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
var x = 1;
a();
b();  
console.log(x);


function a() {
  var x = 10;
  console.log(x);
}

function b() {
  var x = 100;
  console.log(x);
}
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Outputs:

 10

 100

 1
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Memory phase mein var ko undefined milta hai aur functions directly store hote hain. Execution phase mein values assign hoti hain, isliye output 10, 100, 1 aata hai.
