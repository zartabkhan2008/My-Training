JavaScript Objects

A beginner-friendly guide with examples

What is an Object?

Definition: An object is a collection of key-value pairs. Keys are called properties.

// Example
let person = {
  name: "Alice",
  age: 25,
  isStudent: true
};
console.log(person);

Explanation: Objects let us group related data together in one structure.

Accessing Properties

Definition: You can get values from an object using dot . or bracket [] notation.

// Example
let car = { brand: "Toyota", year: 2020 };
console.log(car.brand);     // Toyota
console.log(car["year"]);   // 2020

Explanation: Dot notation is simpler, while bracket notation is useful when the property name is dynamic.

Adding Properties

Definition: You can add new properties to an object at any time.

// Example
let book = { title: "JS Basics" };
book.author = "John Doe";
console.log(book);
// { title: "JS Basics", author: "John Doe" }

Explanation: Objects are flexible — you can add new properties whenever needed.

Removing Properties

Definition: Use the delete keyword to remove a property.

// Example
let user = { name: "Alice", age: 25 };
delete user.age;
console.log(user); // { name: "Alice" }

Explanation: Removing properties is simple, but be careful not to delete important data.
