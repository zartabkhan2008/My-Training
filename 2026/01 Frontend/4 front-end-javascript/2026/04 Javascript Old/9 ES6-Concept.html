📘 ES6 Concept with Examples

📌 Core Features

let keyword – Block-scoped variables.

for (let i = 0; i < 3; i++) {
  console.log(i);
}
// i is not accessible outside the loop

const keyword – Constants cannot be reassigned.

const PI = 3.14;
// PI = 3.14159 ❌ Error

Arrow functions – Concise syntax, inherit this.

const add = (a, b) => a + b;
console.log(add(2, 3)); // 5

Destructuring assignment – Extract values easily.

const person = {name: "Alice", age: 20};
const {name, age} = person;
console.log(name, age);

Spread operator – Expands arrays/objects.

const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4];
console.log(arr2); // [1,2,3,4]

For/of loop – Iterates over iterable objects.

for (const char of "ES6") {
  console.log(char);
}

🔑 Advanced Features

Maps – Key-value pairs.

const map = new Map();
map.set("a", 1);
console.log(map.get("a")); // 1

Sets – Unique values only.

const set = new Set([1,2,2,3]);
console.log(set); // {1,2,3}

Classes – OOP-style syntax.

class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    console.log(this.name + " makes a sound");
  }
}
const dog = new Animal("Dog");
dog.speak();

Promises – Handle async operations.

const promise = new Promise((resolve, reject) => {
  setTimeout(() => resolve("Done!"), 1000);
});
promise.then(result => console.log(result));

Default parameters – Function defaults.

function greet(name = "Guest") {
  console.log("Hello " + name);
}
greet(); // Hello Guest

✨ Additional Enhancements

Template literals – Embed expressions.

const name = "Bob";
console.log(`Hello, ${name}!`);

Modules – Import/export.

// file1.js
export const num = 42;

// file2.js
import { num } from './file1.js';
console.log(num);

Rest parameters – Collect arguments.

function sum(...nums) {
  return nums.reduce((a,b) => a+b, 0);
}
console.log(sum(1,2,3)); // 6

Generators – Pause/resume functions.

function* gen() {
  yield 1;
  yield 2;
}
const g = gen();
console.log(g.next().value); // 1

Symbol – Unique property keys.

const sym = Symbol("id");
const obj = { [sym]: 123 };
console.log(obj[sym]);
